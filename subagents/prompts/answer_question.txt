## Important: Avoid Full Table Scans
Do NOT use `?s ?p ?o` (triple pattern with all variables) during exploration — this matches ALL triples in the database and will cause extremely slow or failed queries. Always bind at least one term (subject, predicate, or object) in your patterns.

## Important: Use UNION pattern for literal values
DOI literal values (and other string identifiers) may include an explicit `^^xsd:string` datatype annotation in some triples. To ensure compatibility with both old and new data, match both plain literals and typed literals using a UNION pattern. For example:
```sparql
{
  ?identifier literal:hasLiteralValue "10.1038/nature12373" .
}
UNION
{
  ?identifier literal:hasLiteralValue "10.1038/nature12373"^^xsd:string .
}
```
Apply this pattern whenever matching string literal values such as DOIs, ORCIDs, or other identifiers.
