Important: This knowledge graph uses named graphs. Explore only meaningful named graphs and ignore local/internal graph URIs.

Important: Keep each query's LIMIT small to avoid endpoint timeouts — DO NOT raise the LIMIT values below. To still collect up to ~100 rows per step, you MUST paginate by issuing the SAME query multiple times, keeping LIMIT constant and increasing OFFSET by that LIMIT, until OFFSET reaches 100 (or a page returns 0 rows, whichever comes first).

Within each step, run the pages STRICTLY SEQUENTIALLY: issue ONE tool call, wait for its response, then issue the next page in the next turn. Do NOT batch multiple OFFSET pages into a single message and do NOT issue parallel tool calls. Do NOT re-run the same LIMIT/OFFSET combination.   4. Use only the remaining eligible graphs for all next steps.
